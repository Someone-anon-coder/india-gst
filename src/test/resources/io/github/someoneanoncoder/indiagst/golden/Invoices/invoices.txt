# 50 worked GST invoices for TaxCalculator and PlaceOfSupply (plan L2-08).
#
# Status: DRAFT, awaiting owner review. Lines starting with '#' are the arithmetic worked out per line.
# Provenance: inputs were chosen by hand to cover each rule. Expected figures were NOT produced by the
# Java implementation; they were computed with a separate throwaway Decimal script and the key cases
# re-checked by hand (case 01, 05, 31-34, 36, 37, 46). Review the cases flagged AMBIGUOUS/ASSUMPTION/UNVERIFIED.
#
# Conventions (all documented on TaxCalculator): each line rounded half-up to paise on its own;
# intra-State: each half = taxable x rate/2 rounded; inclusive: taxable = price x 100 / (100 + gst + cess)
# rounded half-up, cess = taxable x cess rounded and capped at the tax part, the rest is GST, an odd
# paisa goes to central tax.
#
# Record format (pipe separated):
#   case|<no>|<title>   supplier|<state code>   delivery|<state code>   buyer|<GSTIN>   mode|EXCLUSIVE or INCLUSIVE
#   line|amount|discount|gst rate|cess rate
#   expect-type|INTRA_STATE or INTER_STATE   expect-state-tax|SGST, UTGST or NOT_APPLICABLE
#   expect-line|taxable|central|state|integrated|cess      (one per line, in order)
#   expect-summary|gst rate|cess rate|taxable|central|state|integrated|cess      (ascending rate)
#   expect-total|taxable|central|state|integrated|cess|grand total
#   roundoff|mode|payable|adjustment
