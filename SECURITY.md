# Security policy

Report vulnerabilities privately through GitHub: Security tab, "Report a vulnerability". Please do not open a public issue.

Scope: incorrect tax arithmetic that silently loses or creates money, GSTIN or invoice-number validation that accepts or rejects wrongly, unbounded resource use or XML/zip attacks when parsing untrusted text or spreadsheets, and supply-chain problems. Expect an acknowledgement within a week.

Supported versions: the latest 0.x release.
